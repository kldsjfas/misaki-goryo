# 美咲的太刀：真龙御礼

> 拔刀剑 Resharped 附属模组 · Minecraft 1.20.1 Forge · 模组 ID `misaki_goryo` · 版本 1.0.4
>
> 本模组为《吉星派对》同人作品，与《吉星派对》官方无关。

## 简介

一把从神社练武场里最普通的红柄练习太刀开始，一路重铸、觉醒，最后成为「真龙御礼」的成长太刀。

刀一共五阶。四阶「嘎呜切·龙纹」觉醒时，刀灵**龙崎美咲**会从刀里走出来，以 Q 版小人的样子飘在你身边：跟着你转头、眨眼、打哈欠，遇到下雨、天黑、受重伤、精英怪时会冒出一句话。五阶「真龙御礼」时她会换上龙王祭的礼装。

五把刀都是拔刀剑的原生命名刀（自带模型、拔刀剑原版连招、耀魂/击杀/精炼计数），可以正常放刀架、用铁砧精炼。

## 五阶太刀

| 阶段 | 名字 | 基础攻击 | 耐久 | 特殊攻击 |
|---|---|---|---|---|
| 一阶 | 练习太刀·樱 | 4 | 160 | 拔刀剑原版次元斩 |
| 二阶 | 樱吹雪 | 5 | 180 | 樱花裂空斩 |
| 三阶 | 名刀·嘎呜切 | 6 | 300 | 樱花裂空斩（带剑气） |
| 四阶 | 嘎呜切·龙纹 | 7 | 420 | 次元斩 |
| 五阶 | ✦ 真龙御礼 ✦ | 8 | 600 | 次元斩·真龙 |

基础攻击按原版拔刀剑的尺度设定（原版铁质无铭刀约 4，钻石/下界合金无铭刀 7～8），后期强度主要来自特殊攻击和五阶被动。所有刀自带耐久Ⅰ。

### 特殊攻击

二到五阶的特殊攻击是本模组自带的，每次消耗 20 耀魂。每一段的伤害都等于**你当前的攻击力 × 倍率**，所以精炼、附魔、药水带来的攻击力提升都会一起算进去。

- **樱花裂空斩**（二、三阶）：向前小冲一步，对前方扇形约 10 格内的敌人连斩 3 段，每段 1.0 倍攻击力。冷却 3 秒（三阶 5 秒）。
- **次元斩**（四阶）：以准星前方为中心，对半径约 9 格内的敌人斩 4 段，每段 0.6 倍攻击力，最后一段翻倍。冷却 8 秒。
- **次元斩·真龙**（五阶）：先把身边 7 格内的敌人定住 1 秒，再斩 4 段（每段约 0.96 倍攻击力），最后一条青龙沿直线冲出 25 格（1.5 倍攻击力）。冷却 8 秒。

特殊攻击之间共享冷却，同一时间只会放一个。

### 剑气（三阶起）

用拔刀剑普通连招连续砍中**同一个**敌人会叠剑气，最多 3 层。叠满后下一次特殊攻击会被强化（范围更大、伤害 ×1.5～1.7），然后剑气清零。换目标会重新计数。

### 刀灵·美咲（四阶起）

- 四阶、五阶刀拿在主手时，美咲会出现在你右前上方；第一人称时她固定在画面右上角。
- 默认按 **Alt + H** 收起或唤出（可以在按键设置里改）。
- 她不会受伤、不挡路、不参与战斗，只负责陪你和说话。

### 御刀飞行（四阶起）

四阶、五阶刀拿在主手时可以像创造模式一样飞（双击空格）。换下刀时如果还在空中，会给几秒缓降，不会直接摔死。服务器可以在配置里关闭。

### 真龙御礼的被动（五阶）

| 被动 | 效果 |
|---|---|
| 龙威 | 每次命中叠 1 层，每层伤害 +4%，最多 10 层；6 秒没打中东西就清空 |
| 青龙雷 | 每第 3 次命中，引雷劈中附近 8 格内最近的 4 个敌人，伤害为攻击力的 50% |
| 龙王裁决 | 每次伤害额外附加目标最大生命 2% 的真实伤害；Boss（`forge:bosses` 标签里的实体）只吃 0.5% |
| 真龙之躯 | 持刀时受到的伤害 -25%；免疫摔落、火焰、熔岩、溺水、窒息伤害；造成伤害的 2% 转为生命（单次最多回复最大生命的 10%） |
| 龙魂不灭 | 持刀时受到致命伤，改为回到一半生命并获得抗性提升Ⅳ 3 秒、生命恢复Ⅱ 10 秒；冷却 15 分钟 |
| 满层斩 | 龙威满 10 层时放特殊攻击，会消耗全部龙威，让最后一记青龙伤害翻倍 |
| 龙王祭的祝福 | 刀在身上（快捷栏、背包、副手都算）就有急迫、速度、夜视、水下呼吸、幸运；握在主手时还会免疫并清除所有负面效果 |

## 合成与成长

所有材料都来自原版或拔刀剑本体。合成用普通工作台，旧刀的击杀数、耀魂、精炼次数、附魔、自定义名字都会继承到新刀上。

**一阶 练习太刀·樱**

```
[ ]     [铁锭]  [粉红色花簇]
[ ]     [木棍]  [铁锭]
[木棍]  [ ]     [ ]
```

**二阶 樱吹雪**：练习太刀·樱需要至少 **30 击杀**

```
[ ]         [耀魂铁锭]   [ ]
[樱花木板]  [练习太刀·樱] [樱花木板]
[ ]         [铁锭]       [ ]
```

**三阶 名刀·嘎呜切**：樱吹雪需要至少 **100 击杀、500 耀魂**

```
[ ]          [耀魂宝珠]  [ ]
[鹦鹉螺壳]   [樱吹雪]    [鹦鹉螺壳]
[ ]          [海洋之心]  [ ]
```

**四阶 嘎呜切·龙纹**：不用合成。把嘎呜切拿在主手，刀上累计 **300 击杀、2000 耀魂** 后会自己觉醒，美咲随之出现。数值没到时刀会偶尔在动作栏提示还差多少。（两个数值都可以在配置里改。）

**五阶 真龙御礼**：嘎呜切·龙纹需要至少 **精炼 10 次**（在铁砧上用耀魂类材料精炼）

```
[ ]          [耀偏方三八面魂]  [ ]
[青金石块]   [嘎呜切·龙纹]    [青金石块]
[ ]          [龙首]           [ ]
```

耀魂铁锭、耀魂宝珠、耀偏方三八面魂都是拔刀剑本体的材料（耀魂碎片 → 耀魂铁锭 → 熔炉烧成宝珠 → 高炉烧成结晶 → 高炉烧成偏方三八面魂）。龙首可以在末地城的末地船上找到。

每一阶都有对应的进度（进度页「拔刀」分支），可以用来确认成长到了哪一步。

## 配置

`config/misaki_goryo-common.toml`：

| 选项 | 默认 | 说明 |
|---|---|---|
| `arts.sakuraPulseMultiplier` | 1.0 | 樱花裂空斩每段伤害倍率 |
| `arts.dimensionCutPulseMultiplier` | 0.6 | 次元斩每段伤害倍率 |
| `arts.dragonPulseMultiplier` | 0.6 | 次元斩·真龙每段基础倍率 |
| `arts.sakuraCooldownTicks` 等 | 60 / 100 / 160 | 三种特殊攻击的冷却（tick） |
| `growth.awakenKills` | 300 | 嘎呜切觉醒需要的击杀 |
| `growth.awakenProudSouls` | 2000 | 嘎呜切觉醒需要的耀魂 |
| `passives.bladeFlight` | true | 四、五阶刀是否给飞行 |

## 指令（需要 OP）

- `/goryo give <entry|sakura|gawoo|gawoo_awakened|dragon>`：直接拿一把对应的刀，方便服主和做整合包的人测试。
- `/goryo art`：让主手里的刀立刻放一次特殊攻击。

## 关于语音

模组内置《吉星派对》龙崎美咲的中文、日文原音，随四阶、五阶太刀的刀灵事件播放，无需另装语音资源包。

客户端配置位于 `config/misaki_goryo-client.toml`，`voiceLanguage` 默认为 `"zh_cn"`（中文）；改为 `"ja_jp"` 可使用日文语音。

语音音频的权利归《吉星派对》官方及相关权利人所有，不适用本项目代码的 MIT 许可。

## 构建

`libs/` 里需要放 `SlashBladeResharped-1.20.1-1.1.23.jar`（编译依赖，不会打进成品）。

```
./gradlew build
```

成品在 `build/libs/misaki_goryo-1.20.1-<版本>.jar`。离线构建可以加 `--offline`，前提是 Gradle 缓存里已经有 ForgeGradle 6.0.54 和 Forge 1.20.1-47.4.28 的 userdev。

## 目录

- `src/main/java/com/luckystar/misakigoryo/`
  - `BladeCatalog`：五把刀的定义（攻击、耐久、特殊攻击、模型）。
  - `BladeArts` / `BladeCombat`：二到五阶特殊攻击的注册、表现和分段伤害。
  - `DragonBlade`：真龙御礼的被动。
  - `GoryoBladeService`：合成继承、四阶自动觉醒、进度。
  - `GoryoSpiritEvents` / `MisakiSpirit*` / `GoryoVoice`：刀灵美咲（实体、模型、动作、气泡台词、中日语音）。
  - `GoryoFlight`：四阶起的御刀飞行。
  - `GoryoConfig`：通用配置。
- `src/main/resources/data/misaki_goryo/`：命名刀定义、合成表、进度。
- `src/main/resources/assets/misaki_goryo/`：刀模型、美咲贴图与骨骼数据、语言文件、音效定义。
- `src/main/resources/assets/simplytooltips/`：可选的 SimplyTooltips 提示框主题。

许可见 `LICENSE`（代码 MIT）与 `NOTICE.txt`（美术、角色与语音来源）。
